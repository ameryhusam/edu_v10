## 1. الفلسفة المعمارية الجديدة: الهوية التلقائية واللغة العربية أولاً

```
                          ┌─────────────────────────────────────────┐
                          │   المدخلات البشرية / ملفات المنهج       │
                          │ • رقم الوحدة (1, 2, ...)                │
                          │ • رقم الدرس (1, 2, ...)                 │
                          │ • الاسم العربي الطبيعي                  │
                          └────────────────────┬────────────────────┘
                                               │
                                               ▼
                          ┌─────────────────────────────────────────┐
                          │   محرك المعالجة والاشتقاق الحتمي         │
                          │ (Deterministic Identity Engine)         │
                          │ • UnitKey:    <TextbookKey>-U01         │
                          │ • LessonKey:  <UnitKey>-L02             │
                          │ • ConceptKey: <LessonKey>-C01           │
                          │ • QuestionKey:<LessonKey>-Q<Hash>       │
                          └────────────────────┬────────────────────┘
                                               │
                                               ▼
                          ┌─────────────────────────────────────────┐
                          │  قاعدة البيانات (PostgreSQL / Prisma)   │
                          │  ربط متكامل، سلامة تامة، وصفر جهد إنجليزي│
                          └─────────────────────────────────────────┘
```

### 1.1 إلغاء الاعتماد على الـ `slug` الإنجليزي اليدوي
- **سابقاً:** كان يُطلب من المعلم أو المؤلف ملء حقول تقنية معقدة مثل `unitSlug: ALGEBRA` أو `lessonSlug: LINEAR-EQUATIONS`.
- **الآن:** تم إلغاء إلزامية الـ `slug` اليدوي تماماً. يعتمد النظام حصرياً على:
  1. **الترقيم الهيكلي الطبيعي للمنهج:** (الوحدة 1، الدرس 2، المفهوم 3).
  2. **الاسم العربي الحقيقي:** يُستخدم كما هو للعرض، ويقوم النظام باشتقاق المفتاح تلقائياً داخلياً دون أن يرى المعلم أي رمز إنجليزي.

### 1.2 معادلة اشتقاق المفاتيح التلقائية الموحدة
تولد النواة (`src/shared/kernel/identifiers.ts`) المفاتيح بطريقة متسقة ودقيقة 100%:
$$\text{UnitKey} = \text{TextbookKey} + \text{"-U"} + \text{Pad2}(\text{unitOrderIndex})$$
$$\text{LessonKey} = \text{UnitKey} + \text{"-L"} + \text{Pad2}(\text{lessonOrderIndex})$$
$$\text{ConceptKey} = \text{LessonKey} + \text{"-C"} + \text{Pad2}(\text{conceptOrderIndex})$$
$$\text{QuestionKey} = \text{LessonKey} + \text{"-Q"} + \text{stableKeyFingerprint}(\text{questionText})$$

*مثال حي:*
- كتاب P1: `EDU-MATH-G07-P1-ED2026`
- الوحدة 1: `EDU-MATH-G07-P1-ED2026-U-ALGEBRA`
- الدرس 2: `EDU-MATH-G07-P1-ED2026-U-ALGEBRA-L-LINEAR-EQUATIONS`
- المفهوم 1: `EDU-MATH-G07-P1-ED2026-U-ALGEBRA-L-LINEAR-EQUATIONS-C-SET`
- السؤال الأول: `EDU-MATH-G07-T01-2026-U01-L02-Qa1b2c3d4`

## 2. خوارزمية المطابقة التسامحية مع الأخطاء (Fault-Tolerant Matching Algorithm)

### 2.1 منطق المقارنة (Comparison Logic)
عند رفع ملف استيراد (Excel أو نصي)، يقوم المحرك بمقارنة عناصر الملف مع هيكل الكتاب الحالي في قاعدة البيانات (`systemOutline`):

1. **البحث برقم الوحدة ورقم الدرس:**
   - يبحث النظام عن الوحدة رقم `U` والدرس رقم `L`.
2. **المقارنة النصية الذكية (Fuzzy Arabic Name Comparison):**
   - تنظيف النصوص العربية من التشكيل، المسافات الزائدة، وتوحيد الهمزات (أ، إ، آ ➜ ا) والياء (ى ➜ ي) والتاء المربوطة (ة ➜ ه).
3. **التصنيف الثلاثي للسجلات:**
   - **سجل متطابق (Exact Match):** الاسم متطابق ➜ يُعتمد تلقائياً وتُربط مفاهيمه وأسئلته فوراً.
   - **سجل جديد (New Record):** رقم درس جديد غير موجود ➜ يُضاف كدرس جديد بترتيبه.
   - **سجل غير متوافق (Discrepancy / Conflict):** رقم الدرس موجود في قاعدة البيانات ولكن باسم مختلف.

### 2.2 شاشة معالجة التضارب على مستوى السجل (Row-Level Resolution UI)
بدلاً من فشل ملف الاستيراد بالكامل وإحباط المستخدم، يتوقف النظام عند السجلات غير المتطابقة فقط ويعرض بطاقة توجيه تفاعلية:

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  ⚠️ تنبيه عدم تطابق في [الوحدة 1] - [الدرس 2]:                              │
│                                                                             │
│  • الاسم المسجل في النظام:  "حل المعادلات الخطية"                           │
│  • الاسم في الملف المرفوع:  "المعادلات الجبرية ذات الخطوة الواحدة"          │
│                                                                             │
│  اختر الإجراء المناسب لهذا السجل (لن يتأثر باقي الملف):                     │
│  [ خيار 1: اعتماد اسم الملف وتحديث النظام ]                                  │
│  [ خيار 2: الاحتفاظ باسم النظام وربط المحتوى بالدرس القائم ]                 │
│  [ خيار 3: تخطي/إلغاء هذا الدرس فقط واستكمال بقية الملف ]                   │
└─────────────────────────────────────────────────────────────────────────────┘
```

**الميزة الكبرى:** إذا احتوى الملف على 30 درساً وكان هناك خطأ في درس واحد فقط، يمكن للمستخدم تخطي الدرس المعطوب أو اعتماده، وسيتم استيراد الـ 29 درساً الأخرى بنجاح 100% دون أي توقف أو تراجع للملف كاملاً.

## 3. استيراد دروس وحدة محددة بشكل مباشر عبر النسخ واللصق (Unit Quick-Paste)

يتيح هذا النمط للمؤلف أو المعلم فتح وحدة دراسية معينة ولصق قائمة دروسها كنص حر مباشر، ليقوم النظام بتحليلها وحقنها فوراً:

### 3.1 التنسيق النصي المقبول (Plain Text / Markdown Format)
يقبل المحلل التنسيق الطبيعي التالي:

```text
الدرس 1: الأعداد الصحيحة والقيمة المطلقة | ص 8 - 15 | المفاهيم: مفهوم العدد الصحيح، الصفر وموقعه، القيمة المطلقة
الدرس 2: جمع وطرح الأعداد الصحيحة | ص 16 - 24 | المفاهيم: قاعدة الإشارات في الجمع، المعكوس الجمعي، الطرح كإضافة المعكوس
الدرس 3: ضرب وقسمة الأعداد الصحيحة | ص 25 - 32 | المفاهيم: ضرب الإشارات المتشابهة، ضرب الإشارات المختلفة، القسمة على الصفر
```

### 3.2 محرك التحليل السريع (Regex Line Parser)
يقوم المحلل باستخراج:
- **رقم الدرس:** من "الدرس 1" أو البداية المسبوقة برقم.
- **اسم الدرس:** النص الذي يلي النقطتين وحتى فاصل `|`.
- **نطاق الصفحات:** من الكلمات المفتاحية `ص` أو `صفحة` (مثل: `8 - 15` ➜ `startPage: 8, endPage: 15`).
- **المفاهيم:** ما بعد كلمة `المفاهيم:` مقسمة بالفواصل (`,`, `،`).
- يتم إنشاء الدروس والمفاهيم وربطها بالوحدة المحددة خلال أجزاء من الثانية.

## 4. محرك النسخ واللصق السريع للأسئلة (Quick-Paste Question Bank)

يتيح للمعلم إضافة عشرات الأسئلة دفعة واحدة دون الحاجة لتعبئة نماذج متعددة، عبر تحديد الكتاب والدرس ثم لصق الأسئلة بنمطين:

### النمط أ: النص البسيط للمعلمين (Simple Text with Asterisk for Correct Choice)

```text
س: ما هو المعكوس الجمعي للعدد -٧؟
أ) -٧
*ب) ٧
ج) صفر
د) ١/٧
[تلميح: المعكوس الجمعي هو نفس العدد بإشارة معاكسة]
[مفهوم: المعكوس الجمعي]
[مصدر: كتاب | تمرين]

س: ناتج العملية (-٤) + (-٦) يساوي:
أ) ١٠
*ب) -١٠
ج) -٢
د) ٢
[مفهوم: قاعدة الإشارات في الجمع]
[خطأ شائع: جمع الإشارات السالبة يغير الإشارة لموجب]
[مصدر: وزاري | 2024-الدور1]
```

- يولد مفتاح السؤال آلياً عبر بصمة النص.
- ينشئ خيارات السؤال ويربط الإجابة الصحيحة.
- يربط المشتتات بالأخطاء الشائعة المذكورة.

## 5. معيار ملف الإكسل المبسط بدون مفاتيح (Zero-Key Excel Standard)

تم تصميم قالب Excel مكون من 4 أوراق عمل واضحة وعربية بالكامل، خالية من أي معرّفات برمجية أو إنجليزية:

### الورقة 1: `01_الهيكل_والمفاهيم` (Units, Lessons & Concepts)
تحدد بنية المقرر بالكامل:

| رقم الوحدة | اسم الوحدة | رقم الدرس | اسم الدرس | من صفحة | إلى صفحة | اسم المفهوم | عتبة الإتقان | صعوبة المفهوم (1-5) |
|:---:|---|:---:|---|:---:|:---:|---|:---:|:---:|
| 1 | الأعداد الصحيحة | 1 | الأعداد الصحيحة والقيمة المطلقة | 8 | 15 | مفهوم العدد الصحيح | 0.80 | 2 |
| 1 | الأعداد الصحيحة | 1 | الأعداد الصحيحة والقيمة المطلقة | 8 | 15 | القيمة المطلقة | 0.85 | 3 |
| 1 | الأعداد الصحيحة | 2 | جمع وطرح الأعداد الصحيحة | 16 | 24 | قاعدة الإشارات في الجمع | 0.85 | 4 |

### الورقة 2: `02_بنك_الأسئلة` (Question Bank)
تعبئة الأسئلة وربطها بالمفاهيم عبر أسمائها العربية فقط:

| رقم الوحدة | رقم الدرس | اسم المفهوم | نص السؤال | الخيار (أ) | الخيار (ب) | الخيار (ج) | الخيار (د) | الإجابة الصحيحة | نوع المصدر | المرجع الوزاري/الكتاب | الخطأ الشائع المرتبط |
|:---:|:---:|---|---|---|---|---|---|:---:|:---:|---|---|
| 1 | 1 | القيمة المطلقة | ما القيمة المطلقة للعدد -٩؟ | -٩ | ٩ | صفر | ١ | ب | كتاب | تمرين صفحة 12 | الخلط بين القيمة المطلقة والمعكوس |
| 1 | 2 | قاعدة الإشارات | ناتج (-٥) + (-٣) = | ٨ | -٨ | -٢ | ٢ | ب | وزاري | MOE-2024-D1-Q03 | جمع السالبين يعطي موجب |

### الورقة 3: `03_البطاقات_الذكية` (Flashcards)
مراجعة سريعة لكل مفهوم:

| رقم الوحدة | رقم الدرس | اسم المفهوم | وجه البطاقة (السؤال أو المصطلح) | ظهر البطاقة (الإجابة أو التعريف) | التلميح |
|:---:|:---:|---|---|---|---|
| 1 | 1 | القيمة المطلقة | ما هي القيمة المطلقة لعدد ما؟ | هي المسافة بين ذلك العدد والصفر على خط الأعداد، وتكون دائماً موجبة أو صفراً. | المسافة لا يمكن أن تكون سالبة |
| 1 | 2 | المعكوس الجمعي | ما هو المعكوس الجمعي للعدد أ؟ | هو العدد (-أ)، وحاصل جمعهما دائماً يساوي صفراً. | اعكس الإشارة فقط |

### الورقة 4: `04_الأخطاء_الشائعة_والعلاج` (Misconceptions & Remediation)
ربط فجوات الإتقان بالموارد العلاجية:

| اسم المفهوم | اسم الخطأ الشائع | وصف الخطأ وسوء الفهم | طريقة التصويب التربوية | عنوان المورد العلاجي | رابط الفيديو أو الشرح |
|---|---|---|---|---|---|
| القيمة المطلقة | الخلط بين القيمة المطلقة والمعكوس | اعتقاد الطالب أن القيمة المطلقة تعكس إشارة أي عدد حتى لو كان موجباً | توضيح أن القيمة المطلقة تجعل الناتج موجباً دائماً لأنها تعبر عن مسافة | فيديو: مفهوم المسافة والقيمة المطلقة | https://media.edu7.app/v/abs-val.mp4 |

## 6. البرومبت المخصص لـ Google NotebookLM لاستخراج الكتب وتعبئة الإكسل

> [!TIP]
> **طريقة الاستخدام:**  
> 1. افتح أداة **Google NotebookLM** وأنشئ دفتراً جديداً (Notebook).  
> 2. ارفع ملف الـ PDF للكتاب المدرسي كاملاً.  
> 3. انسخ البرومبت التالي بدقة والصقه في صندوق المحادثة بـ NotebookLM.  
> 4. سيقوم NotebookLM باستخراج كافة بيانات الكتاب بجداول جاهزة للنسخ المباشر لملف Excel الخاص بـ Edu7!

```markdown
# دورك الأساسي (Role):
أنت "كبير مهندسي المناهج وتصميم التعلم الرقمي لمنصة Edu7 التعليمية الذكية".
مهمتك استخراج وتفريغ محتوى الكتاب المدرسي المرفوع بدقة تحليلية تامة، وتحويله إلى جداول بيانات مهيكلة ومطابقة تماماً لقالب نظام استيراد Edu7 بدون أي مفاتيح برمجية أو رموز معقدة.

# المطلوب استخراجه (Output Requirements):
قم بتحليل الكتاب وإنشاء 4 جداول متسلسلة بتنسيق Markdown Table، بحيث يمكنني نسخها ولصقها مباشرة في ملف Excel:

---

### الجدول الأول: الهيكل والمفاهيم (01_الهيكل_والمفاهيم)
قم بفهرسة الوحدات والدروس والمفاهيم التعليمية الدقيقة داخل كل درس:
الأعمدة المطلوبة بالضبط:
| رقم الوحدة | اسم الوحدة | رقم الدرس | اسم الدرس | من صفحة | إلى صفحة | اسم المفهوم | عتبة الإتقان | صعوبة المفهوم |
القواعد:
- "رقم الوحدة" و "رقم الدرس": أرقام صحيحة متسلسلة (1، 2، 3...).
- "اسم المفهوم": المفهوم الذري الصغير القابل للقياس (Micro-concept) وليس عنوان الدرس العام.
- "عتبة الإتقان": قيمة افتراضية بين 0.75 و 0.85 بحسب أهمية المفهوم.
- "صعوبة المفهوم": رقم تقديري من 1 (سهل جداً) إلى 5 (متقدم).

---

### الجدول الثاني: بنك الأسئلة والتمارين (02_بنك_الأسئلة)
قم باستخراج كافة أسئلة التمارين واختبارات الفصول الموجودة بالكتاب، مع صياغة أسئلة اختيار من متعدد إضافية للمفاهيم التي تفتقر للأسئلة:
الأعمدة المطلوبة بالضبط:
| رقم الوحدة | رقم الدرس | اسم المفهوم | نص السؤال | الخيار (أ) | الخيار (ب) | الخيار (ج) | الخيار (د) | الإجابة الصحيحة | نوع المصدر | المرجع الوزاري/الكتاب | الخطأ الشائع المرتبط |
القواعد:
- "الإجابة الصحيحة": حرف واحد فقط يطابق أحد الخيارات: (أ / ب / ج / د).
- "نوع المصدر": اختر حصراً من: (كتاب / وزاري / معلم).
- "المرجع الوزاري/الكتاب": اكتب رقم الصفحة ورقم التمرين (مثال: تمرين 4 ص 18) أو رقم الامتحان إن وجد.
- "الخطأ الشائع المرتبط": صف الفهم الخاطئ الذي يقع فيه الطالب إذا اختار أحد المشتتات غير الصحيحة.

---

### الجدول الثالث: البطاقات الذكية (03_البطاقات_الذكية)
قم بصياغة بطاقات مراجعة سريعة (Flashcards) تغطي التعريفات، القوانين، والقواعد الأساسية:
الأعمدة المطلوبة بالضبط:
| رقم الوحدة | رقم الدرس | اسم المفهوم | وجه البطاقة (السؤال أو المصطلح) | ظهر البطاقة (الإجابة أو التعريف) | التلميح |
القواعد:
- وجه البطاقة: سؤال مركز وقصير أو مصطلح يحتاج تفسيراً.
- ظهر البطاقة: الإجابة النموذجية المختصرة والواضحة (أقل من 30 كلمة).
- التلميح: جملة إرشادية تساعد الطالب عند التفكير.

---

### الجدول الرابع: الأخطاء الشائعة والعلاج (04_الأخطاء_الشائعة_والعلاج)
حدد الصعوبات والأخطاء الأكثر تكراراً لدى الطلاب في هذا المقرر مع خطة علاجها:
الأعمدة المطلوبة بالضبط:
| اسم المفهوم | اسم الخطأ الشائع | وصف الخطأ وسوء الفهم | طريقة التصويب التربوية | عنوان المورد العلاجي | رابط الفيديو أو الشرح |
القواعد:
- "اسم المفهوم": يجب أن يطابق حرفياً نفس الاسم المستخدم في الجداول السابقة.
- "طريقة التصويب التربوية": خطوة عملية واحدة وواضحة يتبعها المعلم أو الطالب لتجاوز اللبس.
```

## 7. ملخص تجربة المستخدم الجديدة في Edu7

| الميزة السابقة | الميزة المطورة بعد التحديث |
|---|---|
| إجبار المستخدم على كتابة `slug` إنجليزي | **إلغاء تام**؛ الاعتماد على رقم الوحدة والدرس والاسم العربي |
| إجبار المستخدم على معرفة مفاتيح النظام | **إنشاء المفاتيح آلياً 100%** بناءً على الترقيم وبصمة النصوص |
| فشل الاستيراد بالكامل عند وجود خطأ في سطر واحد | **حل النزاعات التفاعلي**؛ تخطي أو تصحيح السجل الفردي واستكمال الباقي |
| تعبئة نماذج معقدة لإدخال الأسئلة | **نسخ ولصق سريع** لأسئلة متعددة بنص مباشر أو JSON |
| صعوبة تفريغ الكتب المدرسية الضخمة | **استخراج آلي عبر NotebookLM** بقالب مهيكل جاهز للنسخ |
