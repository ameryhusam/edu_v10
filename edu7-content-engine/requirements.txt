# With uv:  uv pip install -r requirements.txt

# FREE extraction path:
#   pypdf + Gemini API                    → supported primary fallback path
#   PyMuPDF (optional) + Gemini           → local rendering + visual evidence
#   PyMuPDF + Tesseract OCR               → optional local OCR
#   Ollama local vision model             → optional explicit local adapter
#
# PyMuPDF is intentionally OPTIONAL. The engine must remain installable and
# usable on Android/Termux where PyMuPDF wheels may be unavailable.

# ── Optional local PDF renderer ──────────────────────────────────────

# ── NO OTHER PIP PACKAGES REQUIRED for basic extraction ──────────────
