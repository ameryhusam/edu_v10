# Edu7 Content Engine
منصة معالجة وتجهيز ومقارنة واعتماد المحتوى التعليمي العربي من كتب الـ PDF المدرسية لمنصة Edu7.

## المميزات
1. **استخراج حتمي لـ TOC وخرائط الصفحات (Printed ↔ PDF):** بدون تخمين عبر PyMuPDF.
2. **تقسيم الكتاب إلى وحدات ودروس مستقلة:** كل درس يمثل وحدة معالجة كاملة بحزمته المستقلة.
3. **طبقة نماذج ذكاء اصطناعي متعددة ومجانية:** دعم Qwen3-VL و Gemma 3 و Ollama و Heuristic Micro-Engine المحلي.
4. **مبدأ Evidence-First:** رفض أي مفهوم أو سؤال لا يمتلك دليلاً نصياً في صفحات الدرس.
5. **محرك المقارنة والإجماع:** كشف الخلافات بين النماذج وإجراء المقارنة الدلالية قبل الاعتماد البشري.
6. **تصدير جاهز لمنصة Edu7:** بصيغة JSON المطابقة للمعيار v1.2 ومصنف Excel المعتمد.
