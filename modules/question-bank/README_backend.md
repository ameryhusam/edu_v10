# Backend skeleton notes

This folder contains a minimal Express-based backend skeleton used during PHASE 2A to validate API contracts and integration points. It is intentionally decoupled from Prisma and the main application.

Files
- server.ts: minimal Express routes stubs for health, auth, exams, attempts, imports.

Usage
- This skeleton is for local testing and contract verification. It is not production-ready.
- Real implementation will replace these stubs with Prisma-backed services and proper auth.
